04Meta CAPIServer-side attribution for WhatsApp leadsn8n · Meta APIsRunning
04
Meta CAPI

Rebuilt after the tracking broke

Leads arrive as Click-to-WhatsApp ads. A WhatsApp Cloud API webhook feeds n8n, which keeps only ad-originated messages, dedups them, hashes phone numbers, drops stale events, and posts server-side Purchase events to Meta's Conversions API. Ad sets are managed through the Marketing API. Rebuilt from scratch after a provider change broke attribution.

  1. Webhook intake Catches every inbound WhatsApp message.
  2. CTWA filter Keeps only ad-originated leads.
  3. Dedup and hash SHA-256 on phone numbers, no duplicates.
  4. Staleness check Drops events past their window.
  5. CAPI post Sends server-side Purchase events to Meta.
Server-side, not pixel. Purchase events post directly to Meta's Conversions API with action_source set to website.
Phone numbers hashed. SHA-256 before anything touches Meta, no raw numbers in transit.
Ad sets via API. Managed through the Marketing API with a Meta dev app token, not the ads manager UI.
Rebuilt once already. A provider change broke tracking. This version replaced it end to end.
